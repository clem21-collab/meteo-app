# Fiche Google Play — Météo V5.0

## Nom de l'application
Météo V5.0

## Description courte
Prévisions, radar pluie, vigilance, alertes et statistiques météo.

## Description complète
Météo V5.0 rassemble dans une seule application les informations utiles pour suivre le temps au quotidien.

Consultez la météo actuelle, les prochaines heures et les prévisions sur plusieurs jours, avec température, ressenti, pluie, vent, rafales, humidité, pression et indice UV.

L'application propose également :

- une vue « Aujourd'hui » pour comprendre rapidement la matinée, le midi, l'après-midi, la soirée et la nuit ;
- un radar pluie avec observations récentes et prévisions à court terme ;
- la vigilance officielle Météo-France ;
- des alertes personnalisables pour la pluie imminente, le vent fort, les orages, le gel et la chaleur ;
- la qualité de l'air et les pollens ;
- des statistiques météo sur plusieurs périodes ;
- l'historique récent ;
- la comparaison de plusieurs villes favorites ;
- une vue compacte et un mode hors connexion utilisant les dernières données enregistrées ;
- l'export du résumé météo en image ou en PDF.

La localisation est facultative. Elle permet d'afficher automatiquement la météo correspondant à votre position. Vous pouvez également rechercher une ville manuellement et enregistrer vos villes favorites.

Aucune publicité n'est actuellement intégrée à l'application.

Les données proviennent notamment d'Open-Meteo, Météo-France, RainViewer et OpenStreetMap selon les fonctions utilisées.
